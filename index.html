How TaskEscrow Works

A simple evidence-based verification workflow.

1

Record Funding State

The workflow begins with a configured task and reward amount. Calling mark_funded() records that the task is ready for work submission.

2

Submit Evidence

A public evidence URL is submitted through submit_work(). The contract stores the evidence and moves the task to the submitted state.

3

AI Verification

verify_task() evaluates the evidence using GenLayer nondeterministic AI execution and validator consensus. The final state becomes approved or rejected.

Contract Workflow

Public methods exposed by the TaskEscrow contract.

Write Methods

mark_funded() submit_work(evidence_url) verify_task()

Read Methods

get_status() get_evidence_url() get_task_description() get_reward_amount()
TaskEscrow currently demonstrates an AI-verified task and settlement-decision workflow. The configured reward amount and funded status are recorded as workflow data; this version does not automatically custody or transfer tokens.
